Guia de comandos de rede

Cinco comandos do Windows para descobrir o que está acontecendo quando a internet falha. Abra o Prompt de Comando e teste cada um.

ping

Testa se o seu computador consegue falar com outro e mede quanto tempo a resposta leva.

ping google.com
ping -n 10 google.com
  • tempo=15ms: quanto menor, mais rápida a conexão.
  • Esgotado o tempo limite: o destino não respondeu.
  • O -n 10 manda 10 pacotes em vez dos 4 padrão.

ipconfig

Mostra a configuração de rede do seu computador.

ipconfig
ipconfig /all
  • Endereço IPv4: o endereço do seu computador na rede.
  • Gateway Padrão: o endereço do roteador, por onde você sai para a internet.
  • O /all mostra também o endereço MAC e os servidores DNS.

tracert

Mostra o caminho que os dados percorrem até o destino, roteador por roteador.

tracert google.com
  • Cada linha é um salto (hop) pelo caminho.
  • Se o tempo sobe de repente em um salto, o problema pode estar ali.
  • No Linux e no Mac, o comando se chama traceroute.

nslookup

Pergunta ao servidor DNS qual é o endereço IP de um site.

nslookup google.com
  • O DNS é a "lista telefônica" da internet: troca nome por número.
  • Se o ping por IP funciona e o ping por nome não, o problema é o DNS.

netstat

Lista as conexões ativas e as portas abertas no seu computador.

netstat -an
  • ESTABLISHED: conexão em andamento.
  • LISTENING: porta aberta, esperando alguém se conectar.

Roteiro quando a internet cai

  1. Rode ipconfig e confira se existe um IP e um gateway.
  2. Rode ping no endereço do gateway. Se falhar, o problema é na rede local.
  3. Rode ping 8.8.8.8. Se falhar, o problema está entre você e a internet.
  4. Rode ping google.com. Se falhar só aqui, o problema é o DNS.
